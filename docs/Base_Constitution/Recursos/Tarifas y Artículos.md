Gestión de Tarifas y ArtículosEl sistema de precios se basa en una estructura de agrupaciones flexibles para compras y ventas:Estructura de las TarifasDefinición de Tarifa: Una tarifa es una agrupación lógica que posee una cabecera y un nombre identificativo.Relación con Artículos: Cada tarifa puede contener una cantidad indefinida ($n$) de artículos.Precios Específicos: Dentro de una misma tarifa, se asigna un precio distinto y específico a cada artículo incluido.Asignación y AutomatizaciónVinculación por Defecto: Es posible asignar una tarifa específica a un proveedor por defecto.Agilización de Procesos: Esta configuración permite que, al realizar pesadas o compras, el sistema aplique automáticamente los precios preacordados con dicho proveedor.

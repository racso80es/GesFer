Gestión de la base de datos de los suministradores de material.

Ficha de Proveedor: Contiene datos personales, de contacto y configuración comercial (tarifas y series de facturas por defecto).

Digitalización: Funcionalidad para escanear y almacenar documentos (como el DNI) directamente en la ficha.

Alertas Operativas: Sistema de mensajes de aviso que saltan al seleccionar al proveedor en una compra (ej. "me debe dinero").

Vehículos Asociados: Registro de matrículas y vehículos frecuentes para agilizar el proceso de entrada.

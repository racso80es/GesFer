Definición y configuración de los materiales gestionados.

Ficha Técnica: Cada artículo tiene código, nombre, tipo e IVA asociado.

Lógica de Precios: Configuración de precios de compra y venta por defecto, con capacidad de definir múltiples tarifas personalizadas.

Control de Umbrales: Posibilidad de configurar avisos cuando una compra alcanza cierta cantidad de material.

Informes Oficiales: Configuración específica para la generación de documentación requerida por la administración o la policía.

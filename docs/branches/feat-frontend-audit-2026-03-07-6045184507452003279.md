Esta rama programa la ejecución automática diaria de la auditoría frontend ("Auditoría Frontend Diaria") a través de GitHub Actions. Incluye el script \`frontend-daily.js\` que escanea la arquitectura, calidad del código y convenciones de nomenclatura en \`Shared\`, \`Product\` y \`Admin\`.
